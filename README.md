— Sistema ERP

Sistema ERP (Enterprise Resource Planning) con backend en FastAPI y frontend en Svelte, desarrollado para el curso de Ingeniería de Software.

Sobre el proyecto

Gestiona los procesos centrales de una empresa: clientes, productos, proveedores y ventas, a través de una API REST y un panel de gestión web.

Enfoque
Backend en FastAPI con modelos para clientes, productos, proveedores, ventas y usuarios
Base de datos relacional para persistencia de la información
Frontend en Svelte (gestor-front-aeve) como panel de administración
Definición de casos de uso y requerimientos del sistema
Tecnologías

Python FastAPI Svelte SQLite

Autoría

Trabajo en equipo. Mi parte: infraestructura, API/backend, y levantamiento de casos de uso y requerimientos.
